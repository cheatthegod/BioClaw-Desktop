# Signing key handoff

The Tauri updater signing key was generated on 2026-06-26 and lives at
`.signing-keys/` (git-ignored). You need to do TWO things before the
first release tag:

## 1. Upload the private key to GitHub Secrets

In the repo's Settings → Secrets and variables → Actions, add:

| Secret name                          | Source                                            |
| ------------------------------------ | ------------------------------------------------- |
| `TAURI_SIGNING_PRIVATE_KEY`          | contents of `.signing-keys/bioclaw-signing-key`   |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | contents of `.signing-keys/bioclaw-signing-key.password` |

`release.yml` already reads both via env vars (no workflow change needed).

## 2. Back up the private key

If you lose `.signing-keys/bioclaw-signing-key` AND its `.password` file,
nobody can ship updates that existing installed copies will accept — they'll
reject the new binary and stay stuck on the version they already have. So:

- Copy `.signing-keys/` to 1Password / 1pass-cli (recommended)
- OR copy to a hardware key
- OR copy off-disk

The public key is already pinned in `src-tauri/tauri.conf.json` so it's safe
to commit — but the directory `.signing-keys/` is in `.gitignore` and MUST
never be committed.
