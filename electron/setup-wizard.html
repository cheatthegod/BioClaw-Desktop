BioClaw

AI-Powered Bioinformatics Assistant

BioClaw runs with your full user permissions — it can read and write files, execute commands, and access the network. This is the same security model as Claude Code CLI.

BioClaw installs an isolated scientific Python (~500 MB: scipy, pandas, biopython, matplotlib, typst, …) Nothing is added to your system — everything lives under BioClaw's own data folder.
